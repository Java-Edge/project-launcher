# Executive Update Pattern

Use this pattern for department meetings, monthly reports, weekly reports, project reviews, and OKR/KPI status updates.

## Default deck

### 1. Cover

Purpose: identify the topic and period quickly.

Content:

- project or workstream name
- reporting period
- presenter
- one phrase about the value of the work

Proof object:

- metric rail or short stage indicator

### 2. One-page conclusion

Purpose: give leaders the answer first.

Content:

- 3 takeaways
- red/yellow/green status
- decision or support needed if any

Proof object:

- three status panels or conclusion table

### 3. KPI/OKR alignment

Purpose: show why this work matters to the department.

Content:

- KPI/OKR direction
- target wording
- current-period work
- status

Proof object:

- alignment matrix

### 4. Core proof

Purpose: prove the main progress claim.

Pick one:

- workflow map
- architecture map
- timeline
- metric dashboard
- before/after table

For technical work, keep executive claim above the diagram and precise labels inside the diagram.

### 5. Delivery evidence

Purpose: show outcomes, not task volume.

Content:

- 3-5 completed or advanced deliverables
- evidence counts only if sourced
- what changed because of this work

Proof object:

- evidence board, progress bars, or milestone table

### 6. Risks and solutions

Purpose: make blockers actionable.

Columns:

- risk/blocker
- impact
- solution or next action
- owner/support needed

### 7. Collaboration and process improvement

Purpose: satisfy the "协作" and "工作意义" part of the reporting requirement.

Content:

- role clarity
- cross-team coordination
- AI/process/tooling efficiency examples
- reusable mechanism

### 8. Next plan

Purpose: leave the room with a clear path.

Content:

- 3-5 next actions
- owner and due date when known
- support needed
- boundary of what is not promised

## 3-minute speaking flow

Use this order:

1. "本月核心结论是..."
2. "它对齐的 KPI 是..."
3. "主要证据是..."
4. "当前困难和方案是..."
5. "下周期我会推进..."

Keep one slide per idea. If the speaker needs more detail, create appendix slides instead of overcrowding the main deck.
