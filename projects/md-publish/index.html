使用说明

  1. 第 ① 步填文章的绝对路径（Finder 里选中文件 → 右键按住 option → 拷贝为路径名称）。只粘贴正文不填路径也行，但 playbook 需要落盘文件才能读原文。
  2. 第 ② 步选发布方式。第一次跑请选「存为草稿」，到平台后台看一眼排版再决定直发。
  3. 第 ③ 步点选平台。卡片上标 本机脚本 的已经接好（掘金 / CSDN / 博客园 / 51CTO / 头条号），标 待接入 的只能导出指令；想单跑一家就点卡片上的「只同步这家」。
  4. 点底部「存为草稿 / 直接发布」后，本机 bridge.mjs 会把 playbooks/<平台>.js 喂给 ego-browser 逐条执行——全程没有大模型参与，选择器都是 skill 里实测过的固定路径，所以不限次数、不消耗任何额度。
  5. 进度在第 ④ 步实时刷新；失败的任务会把页面提示原文写进日志（md-publish/logs/job-*.log），照抄报错就能定位。
  6. 平台报「未登录」时：在弹出的 Ego Lite 窗口里登录一次那个平台，再点一次按钮即可（登录态存在 Ego Lite，不影响你日常 Chrome）。
  7. 只想补发其中几个平台：取消勾选别的平台再点按钮。

前置条件：本机装有 ego-browser（桥会在 /api/status 里报告能否找到它），并且页面与桥同源在本机打开。桥只监听 127.0.0.1:8096，不对外提供服务。
